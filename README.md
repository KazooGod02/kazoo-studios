# Kazoo Studios · Simulators

El hub oficial para elegir los Simulators de **Kazoo Studios**, estilo pantalla de selección de personaje de arcade.

| # | Juego | Jugar |
|---|---|---|
| 01 | CÉSAR SIMULATOR | https://kazoogod02.github.io/cesar-simulator/ |
| 02 | KAZOO SIMULATOR: Operación Sin César | https://kazoogod02.github.io/kazoo-simulator/ |
| 03 | JESUS SIMULATOR: El Héroe de Guamúchil | https://kazoogod02.github.io/jesus-simulator/ |
| 04 | CARLOS SIMULATOR | https://kazoogod02.github.io/carlos-simulator/ |
| 05 | DANIEL SIMULATOR: El Ojo de la Primavera | https://kazoogod02.github.io/daniel-simulator/ |

**+18:** todos los juegos tienen humor adulto.

## Controles

- **← →** o **A D**: elegir · **1-5**: directo · **Enter / Espacio / Z**: jugar
- **R**: al azar · **M**: sonido
- Funciona con control (cruceta + A) y en celular (toca para elegir, toca otra vez para jugar).

## Agregar un juego nuevo

Todo vive en `index.html`. Agrega un objeto al arreglo `GAMES` con su color, textos, links y su sprite de 16×16 (`art`: cada renglón son 16 caracteres; `.` deja la cara base).

## Publicar

Es una sola página estática: súbela a un repo y activa **Settings → Pages** con la rama `main` y la carpeta `/ (root)`.
